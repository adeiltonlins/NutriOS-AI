NUTRIOS PREMIUM V5 — UPLOAD FÁCIL PELO GITHUB

Você só precisa substituir 2 arquivos.

1. Extraia este ZIP.
2. Abra seu repositório nutri-chatbot no GitHub.
3. Entre na pasta: app > static
4. Clique em: Add file > Upload files
5. Arraste:
   - app.html
   - nutrios-dashboard-v5.css
6. Commit message sugerido:
   NutriOS Premium v5 - novo dashboard
7. Clique em Commit changes.
8. Aguarde o Render fazer o deploy.

O app.html já aponta para /static/nutrios-dashboard-v5.css.
Não envie o LEIA-ME.txt para app/static; ele é apenas instrução.
